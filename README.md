# 拡張ローマ字入力（AZIK系カスタム配列）仕様・解説書

本定義は、標準的なローマ字入力をベースに、**「長音・二重母音・撥音の一括入力（母音拡張）」**および**「頻出語・助詞・語尾の2打鍵／3打鍵短縮入力」**を追加し、打鍵数を劇的に削減することを目的とした拡張ローマ字定義テーブルです。

---

## 1. 全体コンセプトと特徴

1. **標準ローマ字との完全な上位互換性**
   - 通常の `ka`（か）、`si`（し）などの標準入力はそのまま維持されており、未習得のキーがあっても通常のローマ字入力でスムーズに補完できます。
2. **記号・母音キーを活用した「音便・長音・撥音拡張」**
   - 「〜ん」「〜い」「〜う」など、日本語の音節末に高頻度で現れる母音・撥音パターンを**子音＋記号/特定キーの2打**で入力可能です。
3. **高頻度ワード・助詞・文末表現のショートカット（短縮入力）**
   - 「こと」「もの」「して」「です」「ます」など、日本語の形態素で頻出する2〜3文字を**2〜3打鍵**で素早く打ち抜くことができます。

---

## 2. 母音拡張（二重母音・長音・撥音）ルール

子音キーに続けて右手指周辺の記号キーや特定の文字キーを打つことで、頻出する2文字綴り（音節）を1ストローク相当で入力します。

### ■ 拡張キー対応表（子音 + 拡張キー）

| 拡張キー | 付加される音 | 入力例（子音 `k`） | 入力例（子音 `s`） | 入力例（子音 `t`） | 備考 / 単打（あ行） |
| :---: | :---: | :---: | :---: | :---: | :--- |
| **`-`** | **〜aん** | `k-` → かん | `s-` → さん | `t-` → たん | `\-` → あん |
| **,** | **〜aい** | `k,` → かい | `s,` → さい | `t,` → たい | `\,` → あい |
| **`.`** | **〜uう** | `k.` → くう | `s.` → すう | `t.` → つう | `\.` → うう |
| **`/`** | **〜uん** | `k/` → くん | `s/` → すん | `t/` → つん | `\/` → うん |
| **`;`** | **〜iん** | `k;` → きん | `s;` → しん | `t;` → ちん | `;` → いん |
| **`:`** | **〜oん** | `k:` → こん | `s:` → そん | `t:` → とん | `:` → おん |
| **`c`** | **〜iい** | `kc` → きい | `sc` → しい | `tc` → ちい | `c` → いい |
| **`q`** | **〜eい** | `kq` → けい | `sq` → せい | `tq` → てい | `q` → えい |
| **`x`** | **〜eん** | `kx` → けん | `sx` → せん | `tx` → てん | `x` → えん |
| **`l`** | **〜oう** | `kl` → こう | `sl` → そう | `tl` → とう | `l` → おう |

> **拗音（きゃ・しゃ・ちゃ等）との連動:**  
> 子音＋`y` や `sh`, `ty` の後にも同一ルールが適用されます。  
> - `kyl` → きょう / `shl` → しょう / `tyl` → ちょう  
> - `ky.` → きゅう / `sh.` → しゅう / `ty.` → ちゅう  
> - `ky-` → きゃん / `sh-` → しゃん / `ty-` → ちゃん

## 3. 短縮入力（省略コード）

日本語文章の約30〜40%を占める頻出の助詞・助動詞・名詞・動詞活用形が、子音の組み合わせ（2打鍵および3打鍵）にマッピングされています。

## 4. 特殊キー・記号・編集補助

ホームポジションから離れた記号や編集操作を、左手・ホーム段付近のキーコンビネーションに配置しています。

- **カーソル移動キー:**
  - `@h` → `↑`
  - `@n` → `↓`
  - `@t` → `←`
  - `@s` → `→`
- **句読点・括弧・記号:**
  - `,` → `、` / `.` → `。`
  - `l,` → `‥` / `l.` → `…`
  - `[` `]` → `「` `」`
  - `{` `}` → `『` `』`
  - `~` または `@-` → `〜`
  - `-` → `ー`（長音）
  - `/` → `・`（中黒）
- **促音（っ）:**
  - `kk`, `tt`, `ss` などの二重子音入力に加え、`ltu` / `ltsu` にも対応。

## 5. 打鍵効率の比較例

AZIK定義を用いることで、標準ローマ字に比べて**30%〜50%以上の打鍵数削減**が実現します。

| 入力対象 | 標準ローマ字（打鍵数） | 本拡張テーブル（打鍵数） | 削減率 |
| :--- | :--- | :--- | :---: |
| **とうきょう** | `t o u k y o u` (7) | `t l k y l` (5) / `tkl` (3) | **-57%** |
| **かんがえている** | `k a n n g a e t e i r u` (11) | `k - g a e t r` (7) / `kge tr` (5) | **-55%** |
| **経済産業省**<br>（けいざいさんぎょうしょう） | `k e i z a i s a n n g y o u s y o u` (18) | `k q z , s - g y l s h l` (11) | **-39%** |
| **〜することができます** | `s u r u k o t o g a d e k i m a s u` (16) | `s r k t g a d k i m s` (11) / `sr kt ga dki msu` | **-31%〜** |
| **〜でした** | `d e s i t a` (6) | `d s a` (3) | **-50%** |

## 6. まとめ

- **直感的な拡張母音体系:** 語尾の「ん（`-`, `/`, `;`, `:`）」「長音・重母音（`,`, `.`, `c`, `l`, `q`, `x`）」を記号・余剰キーに規則的に配置。
- **高頻度語の徹底短縮:** 日本語の文章構造（助詞・述部）を2〜3ストロークに圧縮。
- **段階的な習得が可能:** 「まずは母音拡張から」「慣れたら文末短縮コードを導入」といったステップアップが無理なく行える設計となっています。
